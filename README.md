# bsky-labeller-playground
Exploratory tools for working with Bluesky — including helpful scripts for data access, search, and preprocessing. 
The labeler/* folder contains a prototype labeler that can be found at https://bsky.app/profile/labeler-prototype.bsky.social

to use the search script in utils, make a secrets.py with USERNAME and PASSWORD field. Get an app password from  https://bsky.app/settings/app-passwords in your personal account

[how to set up to write labeler code is yet to come but read the labeler/README.md for more information]
All code related to the labeler is in labeler/* 
Pushing to main in labeler/* triggers a Github push to fly.io
